# L01 源实现提取记录

## 来源与范围

- 来源：`game-source/shadow-grudge-iphone.html`
- 关卡配置位置：`LEVELS` 数组，源文件约第 115–117 行。
- 运行时规则位置：初始化约第 224–305 行，更新循环约第 342–430 行，绘制约第 488–530 行。
- 本记录只写源文件中可直接验证的 L01 内容；Unity 映射单独标记为“移植契约”，不把推测写成旧实现事实。

## 可验证的 L01 内容

| 字段 | 源值 | 说明 |
|---|---:|---|
| ID | `1` | HTML 关卡选择中为第一关 |
| 标题 | `第一关 · 它会帮你` | 源配置 `title` |
| 副标题 | `学会让 3 秒前的自己，替你踩住机关。` | 源配置 `sub` |
| 起点 | `startX=64` | 画布坐标；`groundY=472` |
| 玩家尺寸 | `34×44` | `loadLevel` 创建玩家状态 |
| 机关 | `x=272, w=96, label=机关` | 只有“机关”字段，未标记 shadow-only |
| 门 | `x=592, w=44, top=286, plate=0` | 由第 0 个机关控制 |
| 终点 | `goalX=836, goalW=52` | 终点矩形高度为 92，底边取 `groundY` |
| 影子延迟 | `delay=180` 帧 | `shadowAt(180)` 读取历史；HUD 按 60 FPS 显示约 3 秒 |
| 敌人/尖刺/钥匙/检查点 | 无 | L01 配置继承默认值，均为空/false |
| 平台 | 无 | `platforms=[]` |

源文案给出的流程是：玩家先走到黄色机关上并站满 3 秒，离开后向右跑，在门前等待影子重演并踩住机关，门开后冲向绿色终点。源代码的门判定只要求影子或玩家当前压住机关；没有额外的“站满 3 秒”完成条件，3 秒是通过 `delay=180` 让影子出现的等待窗口。源代码还会在玩家站过机关后更新教学提示，但不会把 150 帧作为硬门槛。

## 源运行规则

- 画布为 `960×540`，地面顶边 `groundY=472`。
- 每次 `requestAnimationFrame` 的 `update()` 递增 `frame`，以 `player.vx=±3.9`、重力 `0.7`、跳跃初速 `-13.2` 更新玩家；L01 没有平台或跳跃必需段。
- `history` 每个更新帧记录玩家位置/朝向/行走状态；影子读取 `history[history.length-1-delay]`。
- 机关重叠使用玩家/影子包围盒底部 10 px 与机关区域的重叠；门的开合值以 `0.14` 插值到目标值。
- 进入终点矩形即完成；L01 没有钥匙条件。
- HTML 存档 key 为 `shadowGrudgeSaveV1`，字段至少有 `unlocked`、`completed`、`totalGrudge`、`lastLevel`；完成 L01 会解锁 L02。

## Unity 移植契约

Unity 运行时固定 30 Hz，因此保留源体验的 3 秒延迟时使用 `shadowDelayTicks=90`（而不是直接复制 180 个 Tick）。`legacyDelayFrames=180` 保存在数据中，便于回放诊断。源文件是 2D Canvas，不包含 3D 自由视角实现；V2.0 的 L01 将源机关流程作为行为基线，使用 `Side2D` 起始相机，并在通往庭院的过渡体积中切换到 `Free3D`，这部分是 V2.0 新增实现而不是旧 HTML 已有事实。
